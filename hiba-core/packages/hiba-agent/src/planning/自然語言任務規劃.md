# 自然語言任務規劃

將使用者的自然語言描述轉換為結構化 `ExecutionPlan`（含 `PlanStep[]`），三個可替換模組共同完成：

| 檔案 | 職責 |
|---|---|
| `NLPlanningService.ts` | 核心服務，依賴注入 `LLMClient` 與 `AccountingClient` |
| `HttpLLMClient.ts` | HTTP 呼叫自訓 LLM，支援 OpenAI-compatible / Ollama 格式 |
| `HttpAccountingClient.ts` | 查詢 Accounting Server 取得全節點資源清單（HiBA 資源視圖）|

**設計原則**：介面與實作完全分離，任意替換 LLM 端點或 Accounting Server 不需修改 `NLPlanningService`。
