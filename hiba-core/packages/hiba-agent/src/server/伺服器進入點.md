# 伺服器進入點

`AgentServer`：以 Node.js 內建 `http` 模組包裝 `NLPlanningService`，對外暴露三個端點供瀏覽器（Claw Dashboard）呼叫：

| 路徑 | 方法 | 說明 |
|---|---|---|
| `/health` | GET | 服務存活確認 |
| `/api/resources` | GET | 代理 AccountingClient，回傳全節點資源清單 |
| `/api/plan` | POST | 接受 `{ task: string }` → 回傳 `ExecutionPlan` |

全端點啟用 CORS，預設監聽 `8090` port，可透過 `AgentServerOptions.port` 覆寫。
